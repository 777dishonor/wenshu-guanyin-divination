# 文殊占筮法 · 观音占卜法

两种藏传占卜法的网页版。手机浏览器打开就能用，不用装 App，不用注册，不联网也能用（打开后可以加到主屏幕）。

**在线使用**：<https://777dishonor.github.io/wenshu-guanyin-divination/>

## 两种占法

**文殊占筮法**（36 卦）
麦彭仁波切 造。掷两枚骰子，佛父、佛母各一枚，得一对卦象。重大事宜可连占两次，两遍的吉凶一致则作肯定。

**观音占卜法**（6 卦）
法王松赞干布 造。掷一枚骰子，一数定一卦。只占一次。

汉译：索达吉堪布。

操作很简单：读一遍仪轨 → 写下所问 → 掷骰 → 看卦象。占过的卦会自动留在「过往记录」里，随时可以回看。

## 关于文字

卦象正文依原著录入，未作改动。界面上的文案只是提示，不代替原文。

占卜结果仅供参考，不作决断依据。

## 技术

- 纯静态页面，零框架、零依赖、零统计，不发任何网络请求
- 藏文字体是打包在仓库里的 woff2，不依赖系统字体
- 掷骰、翻页、记录全部在本地完成，数据存在浏览器 localStorage 里，不上传
